# Data availability

The software repository contains deterministic synthetic fixtures only.

The empirical application used a user-controlled source route. Its observation
rows are not redistributed in the software release or the research-output
record. The separate research-output record contains project-generated
simulation outputs, seed registries, configurations, summaries and
figure-source data.

Research-outputs dataset DOI: `10.5281/zenodo.21802337`.

This separation permits independent verification of reported numerical outputs
without republishing upstream observation rows.


## Figure-input data

The software release contains compact, project-generated figure-input extracts under `figures/data/evidence_extracts`. These are derived outputs used solely to reproduce the figures and do not contain upstream electricity price/load observation rows. The associated dataset remains the authoritative source for the full research-output collection.
