# AI and artwork governance

This package provides deterministic, inspectable source files and build scripts. Its existence does **not**, by itself, establish that no AI-assisted tool was used during earlier artwork development. Any statement submitted to a journal must describe the actual workflow truthfully.

For a future non-AI artwork attestation, the author should independently review the source files, make any required edits without AI assistance, run the build locally and retain the resulting build logs and hashes.
