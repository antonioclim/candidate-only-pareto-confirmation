# Source-of-truth hierarchy

1. Frozen numerical evidence objects are authoritative for numerical values.
2. PlantUML sources are authoritative for conceptual semantics.
3. Python scripts are authoritative for data-driven quantitative logic.
4. Normalised OOXML packages are authoritative for the current approved editorial geometry.
5. ODG/PPTX/PNG files under `reference/` are golden regression references, not independent scientific evidence.
