
# Integration status

This figure-generation kit is included in software version 1.2.0 before publication.

- PlantUML sources provide semantic diagrams for F1, F2, F3 and GA.
- Python sources consume frozen derived evidence for F4–F7, S1 and S2.
- Normalised OOXML packages permit exact reconstruction of the current approved editorial geometry.
- The PlantUML executable is not bundled; use the locked version and SHA-256 in `toolchain/plantuml.lock.json`.
- The unpublished manuscript and supplement remain excluded.
