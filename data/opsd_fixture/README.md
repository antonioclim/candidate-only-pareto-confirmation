# OPSD-derived DK1 fixture

This directory contains a 144-hour excerpt aligned from 1-6 January 2019. The first 72 hours are reserved for policy development and the last 72 hours for confirmation. Price and load values are taken from GitHub mirrors of the Open Power System Data 2019 DK1 series at a pinned commit. The authoritative dataset is OPSD Time series 2020-10-06, DOI 10.25832/time_series/2020-10-06.

The fixture is intentionally small and is not represented as the final COR application dataset.
