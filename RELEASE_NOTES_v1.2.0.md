# Release notes v1.2.0

Version 1.2.0 strengthens the one-sided candidate-only confirmation core while
narrowing public claims to what the theory and evidence support.

## Scientific additions

- semantic clarification: the positive certificate establishes strict positive-witness archive separation, which implies but is stronger than ordinary nondominance at equality boundaries;
- paired coordinate, Hotelling and hybrid confirmation;
- shared-candidate Gaussian calibration cells;
- explicit strong-serial-dependence failure evidence;
- machine-readable theory and applicability status;
- answer-map separation between candidate-only confirmation and full-set
  classification.

## Reproducibility additions

- deterministic synthetic fixtures;
- reference-equivalent accelerated kernels;
- 95% coverage gate;
- deterministic mutation and verifier controls;
- separate software and research-output release architecture.

## Data-policy change

Upstream-derived observation rows are removed from the active repository.
Only deterministic synthetic fixtures remain. Project-generated numerical
outputs are supplied in a separate research-data record.

## Non-claims

- no certification of equality-boundary ordinary nondominance;
- no distribution-free validity;
- no temporal-dependence validity;
- no universal superiority;
- no expected-time optimality;
- no complete Pareto-front recovery.

The unpublished article and supplement are not included.
